# План развития «Апгрейда»

## Принципы

- **Главное — «Сегодня».** Открыл приложение — видишь следующую тренировку и цель по каждому упражнению. Всё остальное — по запросу.
- **Офлайн прежде всего.** Устройство — источник правды, база — синхронизация. В зале без сети ничего не теряется.
- **Данные открыты агентам.** Формат выгрузки — это будущий API: то, что сегодня уходит файлом, завтра агент получит напрямую.
- **Корректировки — только с подтверждением.** Агент предлагает, человек применяет; любую корректировку можно выключить или удалить.

## v4 — агенты напрямую

- **Токены доступа** для агентов (личные, с правами «чтение» и «предложить») и API на той же Neon Function:
  - `GET /agent/analysis` — тот же JSON, что и выгрузка;
  - `POST /agent/adjust` — корректировка попадает в приложение как предложение с кнопками «Принять / Отклонить».
- **MCP-сервер** на Neon Functions с инструментами `get_training_summary`, `get_log`, `get_program`, `propose_adjustment` — подключается к Claude как коннектор: «разбери мою неделю» без выгрузки файла.
- **Плановый разбор:** еженедельная задача читает данные и оставляет предложение к понедельнику.
- **Данные часов:** импорт пульса и тренировок (Apple Health через «Команды» → API).

## Модель данных

- **Синхронизация** (таблица `app.kv`, last-write-wins по записи): `settings`, `cycle`, `adjust`, `plan`, `goals`, `swaps` (устарел, переносится в `plan`), `log:<дата>_<A|B|C>`, `meas:<дата>`. Ключи `srv:*` пишет только сервер, например `srv:overlay` — личные заметки владельца.
- **Запись тренировки:** `{ day, block, week, idx, ready, time, ex: { id: [{w, r}] }, rir: { id: "0|1|2|3+" }, s: { joints: { knee|back|elbow|shoulder: 1|2 }, note } }`.
- **Правки программы** `plan`: `{ v: 1, s: { "1A": { g: [связки…], at, ver } }, x: { "ds_0095": упражнение из базы } }` — изменённая тренировка хранится целиком, остальные берутся из программы. В пункте: `orig` — исходное упражнение после замены, `add` — добавлено, `chg` — менялись параметры. Замены «только сегодня» — локально (`daySw`), в журнал попадает то, что сделано.
- **Цикл:** `{ idx, since, hist: [{ at, from, to, why }] }` — `idx` считает недели с начала (15 недель в круге), `since` — с какой даты засчитывается текущая неделя.
- **Корректировка** `upgrade.adjust.v1`: `{ format, title, reason, cycle?, changes: [{ exercise, session?, blocks?, sets?, reps?, rir?, note?, replace_with?, why? }] }`. Полное описание с примером — в поле `adjust_format` любой выгрузки.
