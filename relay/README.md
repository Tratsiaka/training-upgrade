# Прокси для синхронизации

Neon отвечает `403` на все запросы из Беларуси и России, поэтому без VPN приложение не может
ни войти, ни синхронизироваться. Здесь — маленькая функция для Vercel: она работает во
Франкфурте (`fra1`, рядом с базой) и пересылает запросы в Neon Function без изменений.
Ничего не хранит; вход, доступ и CORS проверяет сама Neon Function.

Приложение ходит сначала туда, куда получилось в прошлый раз, а если не вышло — по второму
адресу (`api` и `relay` в `src/app-config.json`).

## Как развернуть (один раз)

1. vercel.com → войти через GitHub.
2. Add New → Project → импортировать репозиторий `training-upgrade`.
3. Root Directory: `relay`. Framework Preset: Other. Остальное по умолчанию → Deploy.
4. Адрес вида `https://<проект>.vercel.app` записать в `src/app-config.json` как `relay` и пересобрать (`python3 build.py`).

Проверка: `https://<проект>.vercel.app/health` → `{"ok":true,...}`.

Переменные окружения (необязательно): `UPSTREAM` — адрес Neon Function,
`ALLOWED_ORIGINS` — откуда разрешены запросы (для ответов об ошибке самого прокси).
